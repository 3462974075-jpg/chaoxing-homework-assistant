# 学习通全自动作业助手 — 设计说明与接口契约

> 版本 v2 · 2026-11-22 · 负责人：Lead（本会话）
> v2 变更（用户下调要求）：不再做「傻瓜式全自动安装」；改为 **免安装绿色版 + 简易 UI + 隐私隔离完善 + 仅 Windows 10/11**。

## 1. 产品目标（v2）

Windows 10/11 x64 上的**免安装绿色版**：把整个目录拷到任意位置，双击 `启动.cmd` 即用；不写注册表、不改系统 PATH、不需要管理员、不创建系统服务。

1. **免安装**：优先使用程序目录内的 `runtime\node`（便携 Node）与 `dsh\`（DSH CLI）；没有则用系统已装的 Node（≥22）/DSH。两者都没有时，可运行一次 `环境准备.cmd`，**只往程序目录内**下载 Node / 安装 DSH，不碰系统。
2. **简易 UI**：单页 4 区块（连接 / 作业列表 / 运行日志 / 设置与隐私），不做多步向导、不做安装动画。
3. **登录**：界面输入学习通账号密码（DPAPI 加密保存在程序目录）；自动登录，遇到滑块/安全验证时提示用户手动完成一次，之后复用 Cookie。
4. **作业**：自动检索未完成作业 → 多选 → 逐项完成；客观题联网检索后自动填写提交；主观/附件题生成文件（有模板按模板）上传提交；缺资料暂停该项并继续下一项。
5. **隐私隔离**：账密 / API Key / Cookie 全部本机 DPAPI 加密；数据只在程序目录内；独立 Edge 配置目录；关闭 DSH 遥测与会话上传；一键清除本地数据。

**范围外**（本次不做）：系统级运行环境自动安装、Python/C++/MCP 依赖安装、安装包/卸载器、跨平台（仅 Win10/11 x64）。

## 5. 接口契约

### 5.1 学习通核心 `cx\index.mjs`

```js
const cx = await createCx({ dataDir, edgeProfileDir, log, sessionStore });  // 不启动浏览器，懒加载
// sessionStore 可选：{ load():Promise<obj|null>, save(obj):Promise<void>, clear():Promise<void> }
// 传入时 Cookie 只经它读写（app 传 DPAPI 加密实现），磁盘不落明文；不传则用 dataDir\session.json

await cx.status()                       // -> { loggedIn, uid, savedAt, expiresAt }
await cx.login({ username, password, onNeedHuman })  // 自动填表登录；onNeedHuman({ reason, screenshotPath })=>Promise
                                        // 需要滑块/短信时：打开可见 Edge，回调让 UI 提示，用户完成后继续
await cx.logout()

await cx.listCourses()                  // -> [{ name, courseId, classId, cpi, enc, entryUrl }]
await cx.listWorks(course)              // -> [{ workId, name, status, left, url, kind }]
                                        //    kind: 'quiz' | 'attach' | 'mixed' | 'unknown'
await cx.openWork(work)                 // 打开作答页，返回 { workId, taskUrl, questions, attachments }
                                        //    attachments: [{ name, url, size? }]
await cx.downloadAttachments(work, outDir)   // -> [{ name, path, ok }]
await cx.fillAnswers(work, answers)     // 只保存不提交 -> { ok, raw }
await cx.submitAnswers(work, answers)   // 正式提交 -> { ok, raw, recordFile }
await cx.uploadAttachment(work, filePath)    // 附件作业上传 -> { ok, raw }
await cx.close()                        // 关闭 CDP 连接（浏览器可保留）
```

### 5.2 AI 引擎 `engine\index.mjs`

```js
const engine = createEngine({ dshHome, dshBin, log });

await engine.ensureHome({ apiKey })       // 写 data\dsh-home\.credentials.yaml（version:1, refs）
await engine.check()                      // -> { ok, version, latencyMs }

await engine.solveObjective({ work, questions, cwd, onEvent })
// -> { answers: {...}, confidence: 0..1, sources: [{title,url}], needMaterials: [], raw }

await engine.makeSubmissionDoc({ work, questions, materials, templatePath, outDir, onEvent })
// -> { filePath, format: 'docx'|'xlsx'|'pptx'|'txt', summary, sources, needMaterials: [] }

await engine.answerShort({ work, question, materials, onEvent })
// -> { text, sources, needMaterials: [] }

await engine.cancel()
```

### 5.2.1 文档生成 `engine\docgen.mjs`（零依赖）

```js
parseDocx(filePath)                  // -> { paragraphs:[{text,style}], tables:[...], text }
newDocx({ title, blocks })           // -> 生成新 .docx（标题/段落/表格，UTF-8）
fillDocxTemplate(templatePath, ops)  // -> 在模板基础上替换/追加：ops=[{find:'{{x}}', replace:'...'} |
                                     //    {after:{text:'题目1'}, insert:[{type:'p',text:'...'}]}]
docxToText(filePath)                 // -> 提取纯文本（供引擎读模板/资料）
xlsxToText / pptxToText              // 可选：至少能 docxToText
```

- 实现：`zlib.inflateRawSync/deflateRawSync` + 自写 ZIP 读写 + CRC32；不依赖 npm 包、不依赖 Python。
- 校验：用系统 `python -c "import docx; ..."` 读回验证（若本机 python-docx 可用），否则用 docgen 自身 `docxToText` 往返验证。
- 模板策略：优先按占位符替换；模板无占位符时，按「题号/段落锚点」在对应位置后追加答案块；无法定位则生成新文档并保留模板原文作附录。

约定：
- **引擎不依赖 DSH 的 shell / 文件工具**（本机实测：nested headless 在沙箱里 `SetNamedSecurityInfoW failed`，shell 与写文件都不可用；在用户机器上也不该依赖）。提示词明确要求：只用推理 + `web_search`，结果以 JSON 文本返回，不写文件、不跑命令。
- 每次调用在**独立工作目录**（`data\jobs\<workId>\engine\<step>\`）执行，只作为 cwd，不要求 DSH 写任何东西。
- 提示词要求模型**先联网检索核对**，答案必须输出严格 JSON（放在 ```` ```json ```` 代码块内），含 `answers` / `sources` / `needMaterials` / `confidence`。
- `needMaterials` 非空 = 缺资料，编排器暂停该项。
- 超时默认 10 分钟（可配）；超时杀进程并返回错误，不卡队列。
- 不允许把 API Key 写进日志。

### 5.4 绿色启动器 `bootstrap\`

- `启动.cmd`（双击入口）：定位程序目录（= 本文件所在目录），按优先级找 Node（`runtime\node\node.exe` → 系统 `node` ≥22）和 DSH（`dsh\` → 系统 `@deepseek-ai/dsh`）；都就绪则启动 `node app\server.mjs`（`CX_APP_ROOT=<root>`）并打开 `http://127.0.0.1:8765`；缺环境则中文提示去运行 `环境准备.cmd`。窗口保持、出错 pause。
- `环境准备.cmd` + `prepare.ps1`：**可选的一次性准备**，只写程序目录——下载便携 Node（nodejs.org / npmmirror 镜像）到 `runtime\node`；用 `npm --prefix <root>\dsh install --global @deepseek-ai/dsh@0.1.7-rc.2` 把 DSH 装进 `dsh\`。不写 PATH、不写注册表、不需要管理员、不动用户 npm 全局。
- `env-detect.ps1`：输出 JSON（node / dsh / python / git 版本与路径），供 app 展示环境状态。
- 卸载 = 删除整个程序目录；不提供卸载器。
- 进度输出约定：`STEP|i|n|名称|状态`、`DONE|版本`、`FAIL|原因`（app 可解析，也可人读）。
- 不做：系统级安装、winget、MCP/Python/C++ 依赖安装。

## 6. 编排流程（Lead）

```
登录并进入个人中心
  └─ 遍历课程 → 拉作业列表 → 过滤「未交 / 待重做 / 未完成」
      └─ 用户选择 N 项 → 队列（顺序执行，避免风控）
          └─ 每项：
             1. openWork → questions + attachments
             2. 判定 kind：
                - quiz：engine.solveObjective → 校验答案 → fill → 校验 → submit
                - attach：下载模板（若有）→ 有缺失资料? 暂停 : engine.makeSubmissionDoc → upload → submit
                - mixed：先做客观题，再做主观/附件
             3. engine 返回 needMaterials → 暂停该项（记录原因），继续下一项
             4. 每步落盘 jobs\<workId>\state.json，可断点续跑
  └─ 全部完成 → 汇总报告（成功/暂停/失败 + 分数/状态）
```

提交策略：默认「自动提交」；设置里可改为「先保存，人工确认后提交」。第一次运行的默认值以设置项 `autoSubmit=true` 为准（用户明确要求全自动）。

## 7. 安全与隐私（隐私隔离是本次重点）

- **数据只在程序目录**：所有运行数据在 `<root>\data\` 与 `<root>\logs\`，不写 %APPDATA%/%LOCALAPPDATA%、不写注册表、不创建计划任务/服务。
- **机密加密**：学习通账密、DeepSeek API Key 存 `data\secrets.dat`（DPAPI CurrentUser）；学习通 Cookie 存 `data\session.dat`（同为 DPAPI，不落明文）。
- **浏览器隔离**：受控 Edge 使用 `data\edge-profile\`（独立配置，不影响用户日常浏览器）；退出不清理以保留登录态，隐私页可一键清除。
- **DSH 隔离**：私有 `DSH_HOME`（`data\dsh-home`），关闭会话日志上传与遥测（profile 补丁）。
- **日志脱敏**：不记录密码/Cookie/API Key；错误信息只保留可读原因。
- **一键清除**：隐私页支持清除 机密 / 登录态 / 日志 / 全部（含 Edge profile 与 DSH 会话）。
- **外联范围**：仅学习通站点与 DeepSeek API（模型请求），不加载第三方 CDN/统计。
- 只操作本人账号；提交会消耗作答机会，UI 明确提示；学术诚信责任由使用者承担。
