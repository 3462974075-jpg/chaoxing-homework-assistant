# 学习通作业助手（绿色免安装版） · v1.4.0

> 作者：**七号玩家（sevenplayer / Lsy）** · 开源协议：MIT License · **Powered by DeepSeek（AI 辅助开发）**

一个放在文件夹里就能用的 Windows 小工具：自动登录学习通、列出未完成作业，勾选后由 AI 帮你完成客观题、主观题和附件题，并在提交前给你完整的进度与结果。支持**图片资料**（拍照的题目/教材页会自动识别成文字），附件作业会自动生成 Word 文档并通过学习通附件上传提交。

> ⚠️ 仅用于**自己的账号**，作业内容请自行核对后再提交；本工具会真实提交作业、消耗作答机会。使用产生的学术诚信责任由使用者承担。

## 运行要求

- Windows 10 / 11（x64）
- Microsoft Edge（系统自带即可）
- 网络：能访问学习通站点与 DeepSeek API
- 运行环境二选一：
  - 电脑已安装 **Node.js ≥ 22** 与全局 DSH CLI（`npm i -g @deepseek-ai/dsh`）；或
  - 双击 **`环境准备.cmd`**：只往本目录下载便携 Node 并安装 DSH（不写系统 PATH、不改注册表、不需要管理员）。

## 第一次使用

1. 双击 **`启动.cmd`**，等待浏览器自动打开 `http://127.0.0.1:8765`（若端口被占用会自动换端口，启动器会打开正确的）。
2. 在「连接」区填写：
   - **DeepSeek API Key**（在 platform.deepseek.com 申请，仅保存在本机）
   - **学习通账号 + 密码**（仅保存在本机，DPAPI 加密）
3. 点「登录」。如果需要滑块/安全验证，会打开 Edge 窗口，手动完成一次即可；之后复用登录态。
4. 点「刷新作业」，勾选要做的作业，点「开始运行」。
5. 运行中可看实时日志；遇到「缺资料」会暂停该项：把资料放进 `data\materials\<workId>\` 后点「继续」。
   - **支持图片资料**（拍照的题目/教材页/老师发的模板截图）：PNG/JPG/WebP 等直接放进去即可，程序会自动用 AI 视觉识别成文字再解题（识别结果缓存在 `data\ocr-cache\`，重跑不重复识别）。
   - 如果个别题目因**内容审核被 AI 拒绝**（暂停详情会列出题号），可在同一目录新建 `manual-answers.json` 手填答案：
     `{"answers":{"215567488":"A","215567489":"BC"}}`，保存后点「继续」，程序会合并手填答案并继续提交。
6. 结束后查看结果汇总。提交记录在 `data\jobs\<workId>\`。
7. 用完后双击 **`停止服务.cmd`** 结束后台服务（关掉窗口不会自动停服务）。

> AI 每次作业有检索次数/时间上限（约 3 次检索、单批最长 5 分钟）。若某项作业提示「AI 检索陷入循环/超时」，按提示补充资料后点「继续」即可，不会影响其他作业。

> **题目很多时（例如 252 道选择题）**：会自动按每批 20 题分批求解，进度显示「第 i/n 批」，整份可能需要几分钟；个别批次被内容审核拒绝时会暂停并提示，已解出的答案会保留，点「继续」只补未解的题。

## 隐私与数据

- 账号密码、API Key、学习通 Cookie 全部用 Windows DPAPI（当前用户）加密保存，界面只显示“已保存/未设置”。
- 所有数据只保存在本目录的 `data\` 与 `logs\`，**不写注册表、不装系统服务、不写用户目录**。
- 使用独立的 Edge 配置目录（`data\edge-profile\`），不影响你日常浏览器的登录状态。
- 「设置与隐私」里可一键清除：机密 / 登录态 / 日志 / 全部数据。
- 除学习通站点与 DeepSeek API 外，不向其他服务器发送数据。

## 目录结构

```
学习通作业助手\
├─ 启动.cmd              # 双击启动
├─ 停止服务.cmd           # 结束后台服务

├─ app\  cx\  engine\  ui\   # 程序本体
├─ bootstap\             # 启动器脚本（start/prepare/env-detect）
├─ docs\                 # 使用说明与界面截图
├─ runtime\node\         # 可选：便携 Node
├─ dsh\                  # 可选：DSH CLI
├─ data\                 # 全部本地数据（可整目录删除）
└─ logs\                 # 运行日志
```

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 双击后提示“运行环境未就绪” | 运行 `环境准备.cmd`，或安装 Node ≥22 与 DSH |
| 浏览器没自动打开 | 手动打开 `http://127.0.0.1:8765`；端口被占用时看 `data\server.json` 里的端口 |
| API Key 总是无效 | 确认是 DeepSeek 平台的有效 Key、账户有余额 |
| 登录失败/卡住 | 确认账号密码正确；需要滑块时在弹出窗口里手动完成；仍失败可清除登录态后重试 |
| 作业状态不刷新 | 点「刷新作业」；学习通偶尔延迟，几分钟后再看 |
| 图片资料识别不出来 | 确认是 PNG/JPG/WebP 图片、画面清晰；识别日志会显示字数；可在 `data\ocr-cache\` 查看识别结果；仍失败可把图片文字手动整理成 `题目.txt` 放进同目录 |
| 杀毒软件拦截 | 本工具会启动 Edge、读写本目录文件，属正常行为；可加入信任 |
| 想换账号/清空数据 | 「设置与隐私」→ 清除本地数据，或直接删除 `data\` 目录 |
| 提示 AI 检索循环/超时 | 该作业需要补充资料（如课本题目截图）；放到 `data\materials\<workId>\` 后点「继续」 |
| 想结束后台服务 | 双击 `停止服务.cmd`（或任务管理器结束命令行含 `app\server.mjs` 的 node.exe） |
| 卸载 | 双击 `停止服务.cmd`，删除整个程序文件夹即可（无系统残留） |
