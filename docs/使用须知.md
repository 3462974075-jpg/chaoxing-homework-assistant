# 学习通作业助手 · 使用须知与步骤（先看这里） · v1.4.0

> 一个绿色免安装的 Windows 小工具：自动登录学习通、列出未完成作业，勾选后由 AI 完成客观题/主观题/附件题，并把结果自动提交。
>
> **⚠️ 必读**：本工具会用**你自己的学习通账号真实提交作业**，会消耗作答机会；AI 生成的内容可能有误。
> 请只用于自己的账号，提交前务必核对；因使用产生的学术诚信责任由使用者自行承担。
>
> **版本：v1.4.0（2026-11-24 · 最终版）**
> 本版重点修复：**AI 引擎自检失败 / “AI 引擎不可用”**——全新电脑或旧版数据里，DSH 运行目录可能只有隐私补丁、缺少基础 profile，或 API Key 只存在 DPAPI 未同步进 DSH_HOME，导致 DSH 启动即失败；现在启动时会自动初始化/修复 DSH 运行目录、自动同步已保存的 API Key，自检失败也会显示具体原因。
> 同时包含：① 版权与作者署名（七号玩家 / sevenplayer / Lsy），Powered by DeepSeek（AI 辅助开发）；
> ② 修复同学电脑已装/未装 Node、DSH 时启动找不到 DSH 的问题（正确使用便携 Node，DSH 缺失时自动补装）；
> ③ 图片资料自动识题；④ 附件作业直接上传；⑤ 批量选择题分批 + 拆单题 + 内容审核拒绝的手动兜底。

## 一、使用前准备

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11（64 位） |
| 浏览器 | Microsoft Edge（Win10/11 自带即可） |
| 网络 | 能访问学习通和 DeepSeek API |
| DeepSeek API Key | 需自己注册并充值（见下文），费用由 DeepSeek 收取 |
| 磁盘空间 | 首次“环境准备”约需 500–600 MB（含 Node + DSH） |

> 压缩包本身只有 2 MB 左右；第一次使用需要联网下载运行环境，之后可离线使用（AI 调用仍需联网）。

## 二、第一次使用（按顺序做）

### 第 0 步：解压

把压缩包解压到**普通文件夹**（例如 `D:\学习通作业助手\` 或桌面）。
不要放在 `C:\Program Files\` 等需要管理员权限的目录；路径可以有中文/空格。

### 第 1 步：双击 `01_环境准备（首次）.cmd`

- 只在**第一次**运行；它会自动往当前程序文件夹里下载便携 Node.js，并安装 DeepSeek Harness（DSH）。
- 联网下载约 3–8 分钟，窗口里会显示进度；**不要关闭窗口**，等出现“完成”后按任意键退出。
- 若电脑已装 Node ≥ 22 和 DSH，可跳过本步。
- 如果下载失败：检查网络/代理后重试；或找一台已准备好的同学，把他的整个程序文件夹拷过来（不要拷 `data\`）。

### 第 2 步：双击 `02_启动.cmd`

- 稍等几秒，会自动打开浏览器，地址是 `http://127.0.0.1:8765/`。
- 如果浏览器没自动打开，手动在 Edge 里打开这个地址即可。
- 窗口不要关（关了也不影响后台服务，但建议保留以便看日志）。

### 第 3 步：填写 DeepSeek API Key（用于 AI 解题/识图）

1. 打开 <https://platform.deepseek.com/> → 注册/登录 → 充值（按量计费）。
2. 在「API Keys」里创建一个 Key，复制（形如 `sk-xxxxxxxx...`）。
3. 回到工具页面「① 连接」区，把 Key 粘贴到 **DeepSeek API Key** 输入框 → 点「保存」。
4. Key 只会用 Windows DPAPI **加密保存在本机程序目录**，不会上传到别处；页面只显示“已保存”。

> 没有 Key 或余额不足时，AI 会报错；请先确认 Key 可用、账户有余额。

### 第 4 步：填写学习通账号并登录

1. 在「① 连接」区填写 **学习通账号 + 密码**（手机号/学号均可，按你平时登录方式）→ 点「保存账号密码」。
2. 点「登录」。
3. 如果需要滑块/安全验证，会弹出 Edge 窗口，**手动完成一次**即可；之后工具会复用登录态（Cookie 加密保存）。
4. 登录成功后页面会显示「已登录学习通」。

### 第 5 步：做作业

1. 点「刷新作业」，会按课程列出你所有**未完成**的作业。
2. 勾选要做的作业（可多选）→ 点「开始运行」。
3. 在「③ 运行」区看实时进度和日志；完成后看结果汇总。

## 三、资料 / 图片怎么放（很重要）

如果作业需要题目原文、教材页、老师模板等资料，程序会暂停并提示「缺资料」。此时：

1. 打开程序文件夹下的 `data\materials\<workId>\`（workId 在暂停提示里会写；也可以点暂停卡片的「打开资料目录」）。
2. 把资料直接放进去：
   - **图片**：PNG / JPG / WebP（拍照、截图都行）——程序会自动用 AI 识图转成文字再解题；
   - **文本**：`题目.txt` / `题目说明.txt`（直接打字的题目）；
   - **Word 模板**：`.docx`（程序会按模板生成提交文档）。
3. 放好后回到页面，点该作业的「继续」。

补充说明：

- 图片越清晰越好；识别失败可在 `data\ocr-cache\` 看识别结果，或改放 `题目.txt`。
- 如果个别题被 AI 内容审核拒绝（暂停详情会列题号），可在同目录建 `manual-answers.json` 手填：
  `{"answers":{"215567488":"A","215567489":"BC"}}`，保存后点「继续」，程序会合并手填答案并继续提交。
- 大批量选择题（如 200+ 题）会自动分批求解，可能需要几分钟，进度会显示「第 i/n 批」，请耐心等待。

## 四、运行与提交说明

- 默认**自动提交**；提交后学习通里可能显示「待批阅」，属正常。
- 若想先检查再提交：在「④ 设置与隐私」里关闭「自动提交」，程序只保存不提交，你确认后再手动提交。
- 运行中可随时点「暂停/继续/停止」。
- 用完双击 **`03_停止服务.cmd`** 结束后台服务（关闭浏览器不会停服务）。

## 五、隐私与安全

- 学习通账号密码、DeepSeek API Key、学习通 Cookie 全部用 Windows DPAPI 加密保存在**本机程序目录**；
- 所有数据只在程序文件夹的 `data\`、`logs\` 里，不写注册表、不装系统服务、不写用户目录；
- 使用独立的 Edge 配置（`data\edge-profile\`），不影响你日常浏览器；
- 可在「④ 设置与隐私」一键清除：机密 / 登录态 / 日志 / 全部数据；
- **不要把自己的 `data\` 目录发给别人**（里面有你的登录态和 Key）；卸载 = 停止服务后直接删除整个程序文件夹。

## 六、常见问题

| 现象 | 处理 |
| --- | --- |
| 双击后提示“运行环境未就绪” | 先运行 `01_环境准备（首次）.cmd`，或安装 Node ≥22 与 DSH |
| 浏览器没自动打开 | 手动打开 `http://127.0.0.1:8765/`；端口被占用时看 `data\server.json` 里的实际端口 |
| 环境准备下载很慢/失败 | 换网络/代理重试；或从已准备好的同学处拷贝整个程序文件夹（不含 data） |
| API Key 保存后仍报错 | 确认 Key 有效、账户有余额、复制完整（以 `sk-` 开头） |
| **AI 引擎自检失败 / AI 引擎不可用** | v1.4 会自动初始化并修复 DSH 运行目录、自动同步已保存的 Key；仍失败请**重新保存一次 API Key**，或删除 `data\dsh-home\` 后重新保存 Key；再不行查看 `logs\` 下的最新日志（界面会显示具体原因） |
| 登录失败/一直等 | 确认账号密码正确；需要滑块时在弹出窗口手动完成；仍失败可「退出登录」后重试 |
| 作业状态不刷新 | 点「刷新作业」；学习通偶有延迟，几分钟后再看 |
| 图片识别不出来 | 换清晰图片；或在同目录放 `题目.txt` 文字版 |
| 提示「AI 检索循环/超时」 | 该作业资料不足，补充资料/题目文字后点「继续」 |
| 杀毒软件拦截 | 本工具会启动 Edge、读写本程序目录，属正常行为；可加入信任 |
| 想换账号/清空数据 | 「设置与隐私」→ 清除本地数据，或直接删除 `data\` 目录 |
| 停止服务 | 双击 `03_停止服务.cmd`（或任务管理器结束命令行含 `app\server.mjs` 的 node.exe） |
